# MEDBOT.AI 🩺🤖

**MEDBOT.AI** is a healthcare assistant bot built on **Telegram** that helps users with:

- 🍎 Food classification (trained on 90+ food images)
- 💊 Symptom checking and disease prediction
- ⏰ Reminders for health activities (like medicine intake, hydration, etc.)
- 🧠 Agentic decision-making through Gemini LLM integration

The bot combines a custom **Teachable Machine** model with **Google Gemini LLM** and **USDA Food API** to provide health-related advice in a conversational way.

---

## 🚀 Features
- **Food Scanner** – Upload food images and get classification + nutritional info.
- **Symptom Checker** – Enter symptoms and get possible disease predictions + advice.
- **Reminders** – Schedule health reminders directly through the bot.
- **Agentic Flow** – The bot intelligently chooses whether to use the symptom model, food model, or LLM.

## ⚙️ Setup Instructions

### 1️⃣ Clone the repo
```bash
git clone https://github.com/yourusername/MEDBOT.AI.git
cd MEDBOT.AI
```

### 2️⃣ Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
```

### 3️⃣ Install dependencies
```bash
pip install -r requirements.txt
```

### 4️⃣ Setup environment variables
Create a **.env** file in the root directory with the following:
```ini
# Paths to models
MODEL_PATH=models/keras_Model1.h5
LABELS_PATH=models/labels.txt

# API Keys
USDA_API_URL=https://api.nal.usda.gov/fdc/v1/foods/search
USDA_API_KEY=your_usda_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here

# Telegram Bot
TELEGRAM_TOKEN=your_telegram_bot_token_here

# Logging
LOG_LEVEL=DEBUG
```

## 🏋️ Training the Model
- The **food classification model** was trained using **Google Teachable Machine**.
- Dataset: 90+ labeled food images.
- Exported model in `.h5` format and used with `keras`.

## 📲 Running the Bot
```bash
python src/main.py
```

Then open Telegram and chat with your bot using the **bot link** generated by BotFather.

---

## 🔑 Core Components
- **Food Model** – CNN trained via Teachable Machine.
- **Symptom Checker** – ML model + Gemini LLM for health advice.
- **Reminder Service** – Background task to schedule notifications.
- **Agentic Main** – Handles which module to call based on user input.
